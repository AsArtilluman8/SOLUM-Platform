# SOLUM Mobile UX Designer

Use this skill for UI/UX tasks.

## Main formula

smart auto -> direct visual control -> compact precision -> advanced override

## Mobile editor laws

1. Viewport/preview is sacred.
   - Target 60 percent or more of screen.
   - Do not cover the object center with panels.
2. One screen = one focus.
3. Progressive disclosure:
   - Basic
   - Pro
   - Advanced
   - Debug
4. Touch before numbers.
5. Bottom sheet states:
   - collapsed
   - half
   - full
6. Debug is a mode, not default UI.
7. Russian labels must fit.
8. Touch target minimum: 44dp.
9. Bottom nav maximum: 4 to 5 tabs.
10. Status uses icon + color + label, not color only.

## Design review checklist

For every screen, check:

- hierarchy;
- spacing;
- contrast;
- touch targets;
- safe bottom zone;
- empty state;
- loading state;
- error state;
- Russian text length;
- viewport visibility;
- debug noise;
- duplicate controls.

## Forbidden

- Desktop UI squeezed into phone.
- Permanent left panel wider than 20 percent.
- Main transform through +X -X buttons.
- More than 5 visible primary controls without disclosure.
- Important icon-only buttons without labels.
