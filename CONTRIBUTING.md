# Contributing to SOLUM Platform

SOLUM is an early-stage open-source project for mobile-first game engine research and Android-based creative tooling.

## Useful contribution areas

- Android and Termux build fixes.
- Filament renderer integration and diagnostics.
- glTF/GLB import and asset pipeline improvements.
- Material inspection and preset tooling.
- Documentation and screenshots.
- Performance profiling on Android devices.
- Procedural asset generation research.
- VFX, water, and world-reaction prototypes.

## Principles

- Prefer maintainable architecture over quick hacks.
- Keep mobile performance in mind.
- Avoid large binary assets unless discussed first.
- Prefer reusable systems over one-off fixes.
- Document important decisions in docs/ or tasks/.
- Use clear commit messages.

## Before opening a pull request

Include what changed, why it changed, how it was tested, device/build notes, and screenshots/logs when relevant.
