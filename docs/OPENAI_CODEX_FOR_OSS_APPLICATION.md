## Why this repository is a good fit

```text
SOLUM Platform is an open-source mobile-first game engine/toolchain for building AAA-style 3D games directly on Android devices. It targets creators without powerful PCs and combines Filament rendering, GLB/IBL tooling, material inspection, procedural asset economy, physical materials, VFX, water, and reactive world systems. I am the primary maintainer and actively develop, test, document, and release the project.
```
