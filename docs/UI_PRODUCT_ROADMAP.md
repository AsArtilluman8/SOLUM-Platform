# UI_PRODUCT_ROADMAP

## Shared SOLUM App Family Style

- dark translucent panels;
- cyan/blue accent;
- compact readable text;
- touch targets at least 44dp, preferably 52dp for primary buttons;
- collapsible panels for Assets, Camera, Debug.

## Engine UI vs Product UI

Engine UI may expose diagnostics and render lab state. Product UI should focus on user workflow and keep debug export in a Debug panel.

## P08 UI Direction

P08 keeps the current Engine screen, but cleans button layout:

- `Import GLB`;
- `Scan Models`;
- `Export Diagnostics`;
- `Export Debug ZIP`;
- camera zoom controls;
- collapsible Assets / Camera / Debug panels.

Full product polish is deferred until renderer/material foundation is stronger.
