# SOLUM Community Plan

Status: public community growth plan.

SOLUM is an open-source mobile-first engine/editor project. Community growth should be based on honest progress, public roadmap, reproducible builds, screenshots, devlogs, and contributor-friendly documentation.

## Goals

- make the project understandable to new users;
- attract testers and contributors;
- collect device performance data across tiers;
- build trust through honest limitations;
- gather feedback on engine/editor workflow;
- prepare for future assets, packages, agents, and Labs.

## Channels

Potential channels:

- GitHub repository;
- GitHub Issues / Discussions;
- Telegram channel/group;
- short-form devlogs such as TikTok / Shorts / Reels;
- public roadmap updates;
- release notes and test reports.

## Content Themes

Useful content themes:

- mobile-first engine development;
- render quality and FPS truth;
- quality profiles and performance targets;
- asset shelf progress;
- transform gizmo progress;
- animation preview;
- material and VFX experiments;
- physics reaction demos;
- agent-assisted game creation;
- open-source contribution updates.

## Community Requests

Ask the community for:

- stars and watches on GitHub;
- device test reports;
- bug reports with screenshots/videos;
- public-domain or license-compatible asset suggestions;
- UI/UX feedback;
- translations;
- documentation fixes;
- package ideas;
- small reproducible demo scenes.

## Device Performance Reports

Performance reports should be device-tier oriented, not personal-device oriented.

A good report format:

```text
Device tier: Baseline / Mid-range / Upper-mid / Flagship
Android version:
GPU family if known:
SOLUM version / commit:
Quality profile:
Scene/model:
Main FPS:
p95/worst/jank:
Active expensive features:
Screenshot/video:
Notes:
```

## Communication Rules

- Be honest about what works and what does not.
- Do not claim AAA quality before the foundation supports it.
- Do not hide performance limitations.
- Do not promise marketplace revenue before the system exists.
- Prefer clear roadmap updates over hype.

## Near-Term Community Milestones

1. public roadmap docs;
2. performance target docs;
3. first stable APK build notes;
4. device test report template;
5. Telegram channel/group setup;
6. short devlogs showing progress;
