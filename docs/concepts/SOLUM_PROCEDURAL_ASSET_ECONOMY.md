# SOLUM Procedural Asset Economy

SOLUM is not an asset warehouse. SOLUM is a variation factory.

The target is a small high-quality base library plus master materials, masks, modular meshes, procedural variation, seed-based generation, and runtime instance variation.

## Core targets

- 20-40 building modules.
- 20-50 reusable props.
- 20-40 nature meshes.
- 10-30 NPC body/head/hair/clothes modules.
- 100-200 strong texture sets.
- 20-40 master materials.
- Thousands of generated variants.

## Critical masks

- dirt
- wetness
- moss
- edge wear
- scratches
- cracks
- burn
- snow
- sand dust
- curvature
- height
- ambient occlusion
- color variation

## Asset intake rule

Every imported asset must answer whether it can become a reusable module, material preset, texture source, mask source, animation source, or procedural variation source.
