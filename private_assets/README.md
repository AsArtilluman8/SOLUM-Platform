# Private Assets

Put local purchased Unreal, Fab, or Marketplace assets outside Git.

Recommended local path:

```text
/storage/emulated/0/Download/SOLUM_PRIVATE_ASSETS
```

The public SOLUM repository must not contain paid files or Unreal native asset sources such as `.uasset`, `.umap`, `.uexp`, `.ubulk`, or `.uplugin`.

This folder is ignored except for this README. Do not copy paid asset packs here for commit.
